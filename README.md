# EcoGrid Intelligence 🌍⚡

A Flutter Android application developed as part of **Google Summer of Code 2025** under [Liquid Galaxy LAB](https://github.com/LiquidGalaxyLAB).

EcoGrid Intelligence monitors power plants, analyzes climate risk, and visualizes environmental data on Liquid Galaxy satellite displays.

## Tech Stack

- **Flutter** (Android)
- **Clean Architecture** with BLoC state management
- **Open-Meteo API** for real-time climate data
- **Liquid Galaxy** integration via SSH

## Getting Started

```bash
flutter pub get
flutter run
```
